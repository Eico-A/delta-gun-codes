# 三角洲行动｜烽火地带改枪码库

这是一个纯静态网页，用来给朋友分享“烽火地带”改枪码。  
不需要 Google Sheets，不需要后端，不需要数据库，数据直接维护在项目里的 `data.csv`。

## 文件结构

```text
delta-gunsmith-codes/
  index.html
  style.css
  script.js
  data.csv
  README.md
```

## 数据文件

网页会自动读取同目录的 `data.csv`。  
`data.csv` 第一行必须是：

```csv
枪械类型,枪名,方案名,改枪码,备注,是否显示
```

示例：

```csv
枪械类型,枪名,方案名,改枪码,备注,是否显示
突击步枪,M4A1,低成本｜稳定过渡,这里放改枪码,便宜够用,是
突击步枪,M4A1,满改｜极限稳压,这里放改枪码,贵但很稳,是
冲锋枪,MP5,近战｜高机动跑图,这里放改枪码,贴脸舒服,是
```

字段说明：

- `枪械类型`：例如 `突击步枪`、`冲锋枪`、`射手步枪`。
- `枪名`：例如 `M4A1`、`MP5`。
- `方案名`：最重要的信息，会重点显示，例如 `低成本｜稳定过渡`。
- `改枪码`：点击复制时只复制这个字段。
- `备注`：简短补充，可以留空。留空时页面不会显示备注区域。
- `是否显示`：只有填 `是` 才会显示。

## 以后怎么维护 data.csv

1. 打开 GitHub 仓库。
2. 点击 `data.csv`。
3. 点击右上角铅笔编辑。
4. 新增、修改或删除一行。
5. 每一行格式为：

```csv
枪械类型,枪名,方案名,改枪码,备注,是否显示
```

6. 保存时点击 `Commit changes`。
7. 等 GitHub Pages 自动更新。
8. 朋友刷新网页即可看到新数据。

## 添加新改枪码

在 `data.csv` 里新增一行，例如：

```csv
突击步枪,AKM,中价位｜低后坐通用,这里放AKM改枪码,适合中距离,是
```

如果备注为空，也可以这样写：

```csv
冲锋枪,MP5,低成本｜新手过渡,这里放MP5改枪码,,是
```

## 隐藏过期改枪码

把对应行最后一列 `是否显示` 改成 `否`，例如：

```csv
突击步枪,M4A1,旧版方案,这里放旧码,已经不用,否
```

刷新网页后，这条方案就不会显示。

## 发布到 GitHub Pages

1. 新建一个 GitHub 仓库。
2. 上传本项目里的全部文件：
   - `index.html`
   - `style.css`
   - `script.js`
   - `data.csv`
   - `README.md`
3. 进入仓库 `Settings`。
4. 找到 `Pages`。
5. `Source` 选择 `Deploy from a branch`。
6. `Branch` 选择 `main`，目录选择 `/root`。
7. 保存后等待 GitHub 生成网址。

生成的网址通常长这样：

```text
https://你的GitHub用户名.github.io/仓库名/
```

这个网址就是发给朋友的链接。

## 注意

- 朋友只能打开网页查看和复制，不能通过网页修改数据。
- 能编辑 GitHub 仓库的人才可以修改 `data.csv`。
- `data.csv` 放在公开仓库里时，里面的数据也是公开可读的，不要放私人信息。
- 直接双击本地 `index.html` 时，浏览器可能限制读取 `data.csv`；发布到 GitHub Pages 后会正常读取。
